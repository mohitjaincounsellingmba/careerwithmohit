## 4. What is the Structure and Syllabus of the MICAT Exam?

**The MICAT exam is a 2-hour-15-minute computer-based test comprising three distinct sections: Section A (Psychometric Test), Section B (Descriptive Creative Test), and Section C (Objective Aptitude Test covering Divergent-Convergent Thinking, Verbal Ability, Quant/DI, and General Awareness).**

```
+-------------------------------------------------------------+
|                     MICAT EXAM BLUEPRINT                    |
+-------------------------------------------------------------+
| Section & Test Component                 | Evaluation Rule  |
+-------------------------------------------------------------+
| Section A: Psychometric Test (36 Qs)     | Strictly Qualifying (No Marks) |
| Section B: Descriptive Test (4 Qs)       | Essay, Argument, Story Writing |
| Section C: Aptitude (4 Sub-Sections)     | Objective Multiple Choice (MCQ) |
| - Sub-section 1: Divergent Thinking      | Creative reasoning patterns     |
| - Sub-section 2: Verbal Ability (VA)     | Vocabulary, Grammar, RC         |
| - Sub-section 3: Quantitative Ability    | Arithmetic, Algebra, DI         |
| - Sub-section 4: General Awareness       | Media, Brands, Marketing Trends |
+-------------------------------------------------------------+
```

> [!IMPORTANT]
> The **Psychometric Test** is an absolute knockout section. If a candidate fails the internal psychometric profile consistency check, their Sections B and C are **not evaluated**, resulting in immediate disqualification.
