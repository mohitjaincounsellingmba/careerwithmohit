## 📊 CAT 2026 Marking Scheme & Exam Pattern

The exam structure and scoring rules are based on the standard 66-question CAT pattern:

| Parameter | Details |
| :--- | :--- |
| **Exam Mode** | Computer-Based Test (CBT) |
| **Total Duration** | 120 Minutes (40 minutes per section) |
| **Total Questions** | 66 Questions |
| **Maximum Raw Score** | 198 Marks |
| **MCQ Marking** | +3 for Correct, −1 for Incorrect |
| **TITA Marking** | +3 for Correct, 0 for Incorrect |
| **Unattempted Questions** | 0 Marks |

### Section-wise Question Distribution:
* **Verbal Ability & Reading Comprehension (VARC):** 24 Questions (19 MCQs, 5 TITAs) · Max 72 Marks
* **Data Interpretation & Logical Reasoning (DILR):** 20 Questions (16 MCQs, 4 TITAs) · Max 60 Marks
* **Quantitative Aptitude (QA):** 22 Questions (14 MCQs, 8 TITAs) · Max 66 Marks
