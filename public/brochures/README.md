# College Brochures Directory

Place your official college PDF brochures in this folder (`public/brochures/`).

### Naming Convention Example:
- `ndim-delhi-brochure.pdf` -> Available at `/brochures/ndim-delhi-brochure.pdf`
- `fostiima-delhi-brochure.pdf` -> Available at `/brochures/fostiima-delhi-brochure.pdf`
- `jaipuria-noida-brochure.pdf` -> Available at `/brochures/jaipuria-noida-brochure.pdf`
- `jims-rohini-brochure.pdf` -> Available at `/brochures/jims-rohini-brochure.pdf`

You can also specify any custom brochure path or online Google Drive/cloud PDF URL in `data/mbaPgdmColleges2027.ts` using the `brochureUrl` field.
